Sample MCQ #2

Choose the correct statement/s about Vitamin C and Scurvy A. It is a heat labile vitamin B. Exclusive breastfeeding can cause scurvy in infancy C. Therapeutic dose of vitamin C is 100-200mg/day D. Vitamin C is predominantly stored in Liver

AA, B, C, D
BA, B, D
CA, C
DB, D
Show Answer & Explanation ▾
✓ Correct Answer: C. A, C

Vitamin C supplements of 100-200 mg/day orally or parenterally ensure rapid and complete cure of Scurvy. The treatment should be continued for up to 3 months for complete recovery. Breastfeeding protects against vitamin C deficiency throughout infancy . In children consuming milk formula, fortification with vitamin C must be ensured. Children consuming heat-treated milk should consume adequate vitamin C-rich foods in infancy. Vitamin C is easily destroyed by prolonged storage, overcooking, and processing of foods. Vitamin C is not stored in the body but is taken up by all tissues; the highest levels are found in the pituitary and adrenal glands.
